## 受付・対象品目の条件

対象品目、数量・サイズ・状態の条件は未整理。解体を伴う専用予約枠は[将来の提供範囲](scope.md)に分ける。

## 予約成立・変更の条件

| ID | 状態 | ルール |
|---|---|---|
| BR-REG-01 | 方針 | 定期便を基本とし、地域ごとに運行する。頻度は週3回程度を目安とし、地域によって異なる。 |
| BR-REG-02 | 方針 | 定期便の予約枠を2週間前から公開できる。利用者は公開された枠から選んで予約する。 |
| BR-REG-03 | 方針・基準未決 | 先払いとし、「予約前日で確定」とする。何の前日か、何が確定するか、締切時刻は Q-01 で確認する。 |
| BR-REG-04 | 方針 | 定期便の回収日3日前から回収業者のオファー募集を始める。 |
| BR-REG-05 | 方針 | 募集時点の予約件数と、その後に追加されると予測する予約をもとに、必要な回収業者数とオファーを決定し、業者に通知する。 |

## 料金・支払いのルール

| ID | 状態 | ルール |
|---|---|---|
| BR-PAY-01 | 方針・詳細未決 | 定期便は先払い。決済の具体的な時点・方法は未決。 |
| BR-IMM-01 | 方針・金額未決 | 即時依頼に対応し、利用者料金は通常料金に追加料金を加える。金額・算定方式は未決。 |
| BR-IMM-02 | 方針・詳細未決 | 即時依頼のオファーはバックヤードアプリを通じて登録業者に通知・募集する。オークション形式で金額を少しずつ引き上げる。増額幅・間隔は未決。 |
| BR-IMM-03 | 方針 | オークションの上限ルールは公開しない。上限の値・算定式・実装方式は未決で、この公開リポジトリにも記載しない。 |
| BR-SOS-02 | 方針・計算元未決 | SOS対応業者に「オファー金額の30%」を一律で渡す。対象となるオファーと精算方法は Q-04 で確認する。 |

利用者の支払額と業者向けオファー金額は区別する。業者向けの増額が利用者の支払額にも連動するかは未決であり、自動的な追加請求の要件とはしない。

## キャンセル・返金のルール

| ID | 状態 | ルール |
|---|---|---|
| BR-CAN-01 | 方針・詳細未決 | 定期便の利用者キャンセル料はなし。キャンセル可能期限、返金の時期・方法、当日や無断キャンセルの扱いは未決。 |

即時依頼・将来の解体枠にも同じキャンセル条件を適用するかは未決。キャンセル料なしという方針を維持しつつ、前払い金の返金手順を定める。

## 回収・引渡し・完了の定義

| ID | 状態 | ルール |
|---|---|---|
| BR-OPS-01 | 方針 | 回収当日は運営側の経路最適化システムが経路と訪問先住所の順序を提示し、業者はその順序に沿って回収する。 |
| BR-OPS-02 | 方針 | 回収品は運営が指定した場所に搬入・引き渡す。 |
| BR-OPS-03 | 方針 | 回収成果をバックヤードアプリに逐次記録する。記録項目と、各段階の完了条件は未決。 |
| BR-OPS-04 | 方針・範囲未決 | 業者には即時オファーよりも、運営が手配した予約分の回収を優先してもらう。拘束範囲・契約条件は未決。 |

## 例外時の判断・対応

| ID | 状態 | ルール |
|---|---|---|
| BR-SOS-01 | 方針 | 交通事故、緊急のSOS、予定に間に合わないなどの場合、業者がSOSアラートを上げる。運営は他の業者にオファーを出して対応を募る。 |
| BR-IMM-04 | 方針・基準未決 | 即時依頼は所定の時刻の3時間前を募集期限とし、不成立なら時間切れとして利用者に回収できない旨を通知する。基準時刻の定義は Q-03 で確認する。 |

## 未決事項

| ID | 確認したい内容 |
|---|---|
| Q-01 | 「予約前日で確定」の前日は回収日前日を指すか。予約内容・受付締切・業者配置・支払額など、何を確定するか。締切時刻はいつか。 |
| Q-02 | 定期便の先払いの時点、キャンセル可能期限、返金方法・時期、当日・無断キャンセルの扱い。即時依頼への適用範囲。 |
| Q-03 | 原文「オファー後、オファー時刻前3時間前」の基準は希望回収時刻か。3時間を切った依頼の扱い、即時依頼の受付・成立条件、不成立時の決済・返金。 |
| Q-04 | SOSの30%は、元の定期便全体・対象予約・残作業・SOS用オファーのどれを計算元にするか。元業者報酬から差し引くか、運営負担か。複数業者で救援する場合の配分。 |
| Q-05 | 即時依頼の通常料金・追加料金・業者報酬の関係、募集額の増額幅・間隔、受諾が重なった場合の決定方法。上限ルールの詳細は非公開で管理する。 |
| Q-06 | 予約枠の容量、予測方法、必要業者数・オファー額の計算、業者不足や予測と実績の差への対応。 |
| Q-07 | 経路の計算条件、再計算の契機、利用者に示す時間の粒度、指定順から変更する条件。 |
| Q-08 | 指定搬入先の条件、回収成果の記録者・項目、回収と搬入の完了条件、引渡し後の責任分担。 |
| Q-09 | 予約分を優先する義務の範囲、業者との契約・支払い条件、SOS対応業者が見つからない場合の対応。 |
