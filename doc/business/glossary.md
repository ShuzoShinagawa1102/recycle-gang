## 用語と定義

| 用語 | 現時点の意味 |
|---|---|
| 定期便 | 地域ごとに設定した日・枠で巡回する回収サービス。利用者が枠へ予約を入れる。利用者自身の自動継続契約・サブスクリプションを意味しない。 |
| 予約枠 | 定期便などの回収を受け付ける日・時間の単位。時間の粒度と容量は未決。 |
| 追加予約予測 | 業者募集時点から、その後に追加される予約の見込み。現在の予約件数と合わせ、必要業者数・オファーの決定に使う。 |
| オファー | 運営が登録業者に提示する回収・対応業務の募集。業務と金額の単位は詳細未決。 |
| 即時依頼 | 通常料金＋追加料金で個別に業者の募集を行う依頼方式。到着までの保証時間は未決。 |
| オークション形式 | 即時依頼の募集でオファー金額を少しずつ引き上げる方式。増額幅・間隔・成立条件は未決。 |
| 経路最適化 | 運営側が回収経路と訪問先住所の順序を計算して業者へ提示すること。計算条件と方式は未決。 |
| バックヤードアプリ | 今回の方針では、業者向け募集通知や回収成果の逐次記録を扱うアプリ。各業務の利用者・権限は別途定義する。 |
| SOSアラート | 事故・緊急事態・遅延などにより回収の継続や予定の履行が難しい場合に業者が出す支援要請。 |
| SOS対応業者 | SOSを受けた再募集に応じて対応する別の業者。 |
| 運営指定場所 | 回収品を業者が搬入・引き渡す先。場所の性質、受入条件、引渡し後の業務は未決。 |
| 解体予約枠 | 対面で時間をかける解体作業などを受け付ける将来の専用枠。 |

## 区別して使う言葉

- **利用者料金**と**業者向けオファー金額**：同じ額とは限らない。増額募集が利用者請求に連動するかは未決。
- **予約受付**・**支払済み**・**業者手配済み**・**予約確定**：別の業務上の概念として整理し、確定条件が決まるまで同一視しない。
- **回収**と**搬入・引渡し**：利用者から物を受け取る段階と、運営指定場所へ物を届ける段階。完了条件は未決。
- **早く予約できること**と**早く回収されること**：それぞれの待ち時間と表示・保証を分けて検討する。
